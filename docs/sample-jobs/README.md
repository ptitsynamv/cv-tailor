# Sample jobs

Plain-text job posts used to try the job-analysis and gap-analysis prompts by hand (Phase 3).

- One post per file, named `<company>-<role>.txt` (e.g. `acme-senior-frontend-engineer.txt`).
- Paste the post text only: title, company, responsibilities, requirements.
- This folder is public: don't include recruiter names, emails or anything personal.
