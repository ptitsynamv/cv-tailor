## 1. One-Sentence Elevator Pitch (For Resume Bullet / Header)
- Node.js + Express REST API for saving and sharing delivery-route notes, with JWT auth, PostgreSQL and Docker Compose.

## 2. Problem Statement & Motivation
- Built to gain backend experience beyond frontend work: API design, authentication, a relational database and containers.

## 3. Tech Stack Matrix
- **Core Framework/Language:** Node.js 22, Express 5, TypeScript
- **State & Data Fetching:** PostgreSQL 16 with Prisma ORM
- **Styling & UI:** None (API only)
- **Backend / Cloud / APIs:** REST API, JWT authentication, OpenAPI docs
- **DevOps & Tooling:** Docker Compose, GitHub Actions, Jest + Supertest

## 4. Key Architectural & Technical Highlights
- **Layered design:** routes → services → repositories, with input validation at the edge.
- **Auth:** JWT access tokens with role-based route guards (owner, viewer).
- **Delivery:** Docker Compose for the API and database; GitHub Actions runs tests on every push.

## 5. Ready-to-Use CV Bullets (STAR Format)
- Designed a layered Node.js/Express REST API with PostgreSQL (Prisma), JWT auth and role-based access.
- Documented the API with OpenAPI and covered endpoints with Jest + Supertest integration tests.
- Containerized the API and database with Docker Compose and set up GitHub Actions CI.
